🧩 Sudoku Solver in C
Welcome to Sudoku Solver, a command-line application written in C that automatically solves a 9x9 Sudoku puzzle using a backtracking algorithm.

📌 Features
Solves any valid 9x9 Sudoku puzzle.

Input and output are displayed in a clean, formatted ASCII grid.

Shows both the original and solved puzzles.

Fast solution time (typically within seconds).

Terminal-based execution with clear, user-friendly formatting.
